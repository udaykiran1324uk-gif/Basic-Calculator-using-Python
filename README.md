# Basic-Calculator-using-Python
Supports basic arithmetic, square root, power operations, keyboard input, and calculation history.
🧮 Python GUI Calculator

This project is a desktop-based calculator application developed using Python and Tkinter. It provides a clean and user-friendly interface to perform basic and advanced mathematical operations. The calculator also includes a history panel to track previous calculations and supports keyboard input for faster usage.

✨ Features

Basic operations: +, -, *, /

Advanced operations: Square root (√), Power (^)

Keyboard support (numbers, operators, Enter, Backspace, Esc)

Calculation history with reuse option

Clear and backspace functionality

Error handling for invalid expressions and divide-by-zero

Clean and responsive GUI built with Tkinter
